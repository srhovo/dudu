# 嘟嘟club · 陪玩选人

> 「请宝宝挑选心仪陪玩」——面向老板/宝宝的陪玩选人与服务展示页面，纯静态、可部署到 GitHub Pages。

## 功能

- **挑选陪玩**：按价位 + 分路双维度筛选（价位旁显示对应人数），双列卡片墙展示自介卡，点击卡片自动播放音介视频
- **服务清单**：价格表 / 预存表 / 活动图 / 礼物单，每项标注更新日期
- **搜索**：支持名字、分路、价位关键字，以及拼音首字母组合（如 `dy`=打野、`zl`=中路、`gbb`=顾北北）
- 底部 Tab 切换三大页面，移动端优先

## 目录结构

```
├── index.html        # 应用主体（界面 + 逻辑，一般不需要改）
├── data.js           # ★ 内容数据（陪玩 / 价格 / 预存 / 活动 / 礼物，日常更新改这里）
└── assets/
    ├── cards/        # 自介卡图片（放这里）
    └── voices/       # 音介视频（放这里）
```

## 素材规范

| 素材 | 推荐比例 | 建议格式 | 存放位置 |
|---|---|---|---|
| 自介卡图片 | **2096:1279（约 5:3）** | png / jpg / webp | `assets/cards/` |
| 音介视频 | **2096:1279（约 5:3）** | mp4 / webm | `assets/voices/` |
| 活动图 | 5:3 及以上 | png / jpg | `assets/`（可选） |

## 部署到 GitHub Pages（一次性）

1. 本仓库 → **Settings → Pages** → Source 选择 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save。
2. 等 1～2 分钟，访问：`https://srhovo.github.io/dudu/`
3. 以后每次 `git push`，页面自动更新。

## 日常更新内容

### 新增 / 修改一位陪玩

1. 自介卡图片放到 `assets/cards/`，音介视频放到 `assets/voices/`。
2. 在 `data.js` 的 `companions` 里加一条（或改对应条目）：

```js
{ id: 'gbb', name: '顾北北', lane: '中路', price: 20,
  tags: ['温柔', '带飞', '声音好听'], intro: '中单法王，三指操作丝滑',
  image: 'assets/cards/gbb.png',
  video: 'assets/voices/gbb.mp4' }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，英文/数字，不能重复 |
| `name` | 是 | 展示名 |
| `lane` | 是 | 分路：打野/中路/射手/辅助/上单/全能 |
| `price` | 是 | 价位数字（单位 r），需在 `prices` 列表内 |
| `tags` | 否 | 标签数组，用于搜索 |
| `intro` | 否 | 一句话自介，用于搜索 |
| `image` | 否 | 自介卡路径；留空显示占位 |
| `video` | 否 | 音介视频路径；留空则点击卡片显示自介卡并提示待上传 |

3. 提交推送：

```bash
git add .
git commit -m "新增陪玩：顾北北"
git push
```

### 修改价格表 / 预存表 / 礼物单 / 活动

都在 `data.js` 的 `services` 里改对应数组；改完把 `updateDate` 更新为当天日期，页面会展示「更新于 日期」。

### 修改价位档位 / 分路分类

改 `data.js` 顶部的 `prices`、`lanes` 数组，页面的筛选按钮与数量会自动重算。

## 常见问题

- **点卡片没视频播放？** 检查该陪玩 `video` 字段是否填了路径、视频是否已放进 `assets/voices/` 并推送。
- **图片变形？** 自介卡请按 5:3 制作；非 5:3 的图会以居中裁剪方式展示，主体建议放在画面中上部。
- **搜索新名字搜不到拼音？** 中文关键字搜索始终可用；拼音首字母依赖 `index.html` 里的拼音字典，新字未收录时可在字典中补一条（`'字':'首字母'`），或直接搜中文。
